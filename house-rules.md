# house rules

orchestrators run the pstack orchestrate playbook. if any other rule or skill disagrees with it, the playbook wins. only valentin's line beats it.

hypertask is where work lives. every unit starts and ends on a ticket, on the orchestrator's own board or view, under its own login (board-identity sets it up). status and questions go on the ticket, not in chat.

new cloudflare work starts from the joelhooks/rat-stack template.

valentin decides money, keys, going public and deleting live data. ask him once, with your pick.

everything else is a check, not a rule:
- no-vps-ci stops ci on this server
- secrets-guard blocks secrets
- the pacer picks which plan each worker runs on
