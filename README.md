# house-rules: fleet tools, hooks and role skills

The rules no longer live here. Valentin's working rules are the valentin-mode skill in vstack: https://github.com/valentinyeo/vstack/tree/main/skills/valentin-mode, plus pstack.

- `fleet/`: the roster scripts (roster-live, roster-announce, solo-wake) and the rest of the fleet tooling.
- `bin/`: the hooks and installers, for example `no-vps-ci`, `house-rules-sync` and `rules-drift`.
- `skills/`: the role skills: design-lead, finance-lead, marketing-lead, support-manager, solo-dev, shipping-update, figma-design and hypertask-triage.
- `systemd/`: the timers that run the fleet scripts.
