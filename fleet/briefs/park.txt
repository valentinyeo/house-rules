 NEVER END A RUN WITH YOUR TICKET LEFT IN PROGRESS (Valentin 2026-11-07, house rule "No column piles up"; the launcher appends this to every lane's brief). If you end with RUNNER IDLE because the ticket cannot move, first park it with fleet/park, from the house-rules checkout (~/.local/share/house-rules/fleet/park), signed in as yourself. Waits on other tickets that are not done: fleet/park <TICKET> --waits-on <BLOCKER1>,<BLOCKER2>. It moves the ticket to its home column (Bugs, Features or Improvements on board 15), links BlockedBy for each blocker and keeps you assigned; fleet/pick then skips it until every blocker is done, then returns it only to you. Waits on Valentin: post ONE Question comment per the hypertask skill, references/tickets.md (vcc comment add <TICKET> --kind question), then fleet/park <TICKET> --valentin. It moves the ticket to Valentin Review, names him and marks the Question. Nothing was built and no PR exists: fleet/park <TICKET> --unstarted. Not sure which? A merged PR with a switch you may not touch, or work that is simply not live yet, is not "done" and not a bug: name the blocker ticket if there is one. Unfinished work that waits on nobody (a PR that fails to build, a fix you could not finish, a red check you could not clear) is never his call: fleet/park <TICKET> --hand-back "<what is left to do>" keeps you as its owner and keeps its PR. It leaves building columns for review or Backlog. Your own next run resumes it. Another runner takes it only after your slot is permanently removed from the roster. Never ask Valentin about it. fleet/park refuses a ticket with a PR for --unstarted. Another runner also holds the ticket and owns the work (a cross-check, a shared infra ticket): fleet/park <TICKET> --release unassigns only you and leaves the ticket and its column to the owner; fleet/park refuses it when nobody else holds the ticket. Only then end with RUNNER IDLE and the reason. Waiting on another ticket for any reason (its release, its merge, its owner, release authority, a CI fix) is fleet/park <TICKET> --waits-on <THAT TICKET>, never a bare RUNNER IDLE. A feature flag is never Valentin's call (house rule: agents switch flags themselves, never ask him): visible UI and design changes ship at Owner + QA and wait for another runner's cross-QA in the QA column, everything else goes to Everyone. Set the flag yourself with ht-flag and carry on; if you cannot finish, fleet/park <TICKET> --hand-back "<what is left>". Never park a ticket on Valentin, and never end IDLE, for a flag switch or a cross-QA.
