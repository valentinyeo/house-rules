# Rat Stack

Read when you start a new app, frontend or page, choose a framework or library, or review an app's stack.

- Rat Stack is our stack: https://github.com/joelhooks/rat-stack.
- Effect is the framework. Foldkit draws every screen. Alchemy deploys to Cloudflare.
- Use only what Rat Stack uses, like StyleX for styling.
- Anything Joel does not use is out: no React, no Tailwind, no UI kits or themes (Tremor, shadcn, Catalyst, daisyUI), no chart libraries.
- Charts are drawn as SVG in Foldkit.
- Android apps: Capacitor around it.
- New apps, frontends and pages start on it.
- Existing apps get a stack review: keep or move, with evidence. Challenge our framework picks. Never keep one by habit.
- `fleet/stack-scan` lists apps off the stack. `/ratstack-transition` plans a move.
